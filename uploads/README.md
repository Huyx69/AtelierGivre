# Atelier Givre

Site vitrine et boutique en ligne de l'Atelier Givre — pâtisserie & chocolaterie artisanale à Artemare (Ain).

## Voir le site en ligne (GitHub Pages)

Le site est prêt à être publié gratuitement avec GitHub Pages :

1. Sur GitHub, ouvre l'onglet **Settings** (Paramètres) du dépôt.
2. Dans le menu de gauche, clique sur **Pages**.
3. Sous **Build and deployment → Source**, choisis **Deploy from a branch**.
4. Sous **Branch**, sélectionne la branche `claude/project-analysis-6f7l1j` (ou `main` si le travail y a été fusionné), dossier **/ (root)**, puis **Save**.
5. Patiente 1 à 2 minutes : le site sera visible à l'adresse
   `https://huyx69.github.io/Atelier-givre/`

## Structure

- `index.html` — la page (structure, styles et logique dans un seul fichier).
- `support.js` — moteur d'affichage (dc-runtime, généré — ne pas modifier à la main).
- `images/` — photos des produits et de la galerie.
- `.nojekyll` — indique à GitHub Pages de servir les fichiers tels quels.

## Voir le site en local

Ouvre simplement `index.html` dans un navigateur (connexion internet requise pour les polices et le moteur d'affichage).
